# JSON 备份说明

PromptDock 的备份包固定使用以下外层结构：

```json
{
  "format": "promptdock-backup",
  "schemaVersion": 2,
  "exportedAt": "2026-08-23T15:00:00.000Z",
  "data": {}
}
```

`data` 包含个人提示词、内置模板覆盖、隐藏内置项、文件夹、收藏、使用记录、变量填写记忆和界面设置。回答收藏与 Notion 令牌存放在独立的存储键中，不会写入备份。导入前会校验固定标识、结构版本和数据结构；未知格式、未知版本或损坏内容不会写入存储。

## 合并

- 导入记录按 ID 覆盖当前同 ID 记录。
- 收藏 ID 与隐藏内置项取并集。
- 文件夹按 ID 合并。
- 使用记录按提示词分别取较大的使用次数和较新的时间，重复导入同一份备份不会重复累加。
- 变量填写记忆按提示词合并，导入方覆盖同一条提示词的记录。
- 当前抽屉宽度、主题和站点开关保持不变。

## 整体替换

通过二次确认后，用备份中的完整 `data` 恢复当前状态。当前未包含在备份中的个人提示词、覆盖和设置会被移除。

导入前建议先导出一次当前数据。V2 使用独立存储键，不读取或迁移旧版数据。
