# PromptDock V2 人工实站验收清单

分别在 Chrome 和 Edge 中从 `dist` 加载 PromptDock，并在 ChatGPT、Gemini 登录态逐项检查。每个平台、浏览器组合都要单独记录结果。

## 安装与注入

- [ ] 扩展管理页显示 PromptDock 2.1.5，且仅有 `storage` 权限。
- [ ] 刷新页面后，当前可见输入框右侧出现且只出现一个按钮。
- [ ] SPA 新建对话、切换历史对话后仍为单实例。
- [ ] 长对话滚动、输入框增高、侧栏开关、窗口调整时按钮不漂移。
- [ ] 右侧空间不足时按钮移动到输入框上方右侧，且不超出视口。
- [ ] 按钮不遮挡附件、语音或发送按钮；抽屉不改变网页原生布局。

## ChatGPT 历史预览

- [ ] 鼠标进入 ChatGPT 页面最右侧 32 px 时出现图二样式的横杠组；悬停条纹约 0.2 秒后，右侧立即出现深灰色提问列表浮层；移开条纹和浮层后自动隐藏。
- [ ] 浮层按时间顺序显示该会话内的用户提问；长文本单行省略、列表可滚动，最新一条以较浅底色突出；滚轮或触控板在列表尚未到顶/到底时不会带动 ChatGPT 页面。
- [ ] 不悬停、悬停新建对话、悬停外部链接或 Gemini 页面时不会发起预览请求或显示浮层。
- [ ] 预览失败时网页无报错、无布局位移，且可继续正常切换、重命名和删除历史会话。

## 工作台与输入

- [ ] 搜索可命中标题、正文和标签；文件夹、标签、收藏筛选正确。
- [ ] 新建、编辑、删除、内置隐藏、单条恢复和全部恢复均正确。
- [ ] 重名变量只显示一个输入项；缺失变量时阻止插入并聚焦错误项。
- [ ] 空输入框直接插入；已有内容时出现追加、替换、取消。
- [ ] 任何路径都不会自动发送消息。
- [ ] 抽屉顶部与网页顶部对齐；大窗口默认宽 360 px、高度最多为窗口的 80%，宽度在 360–640 px 内可调并保持。
- [ ] 非最大化窗口抽屉宽 320 px；抽屉底部停在输入区上方，不遮挡发送按钮。
- [ ] 窄窗口左右各留 8 px，导航和主内容内部滚动正常。

## 图片与备份

- [ ] 选择超过 10 张图片后按设定批量显示；附加后必须由用户手动发送。
- [ ] “下一批”只在当前批次附加成功后可用。
- [ ] 附加失败时当前批次保留，并显示可操作的失败原因。
- [ ] 刷新页面后不会恢复待上传的本地图片。
- [ ] 合法备份先显示摘要；合并与整体替换行为符合 `JSON_BACKUP.md`。
- [ ] 损坏、未知格式或非 V2 JSON 不会改变当前数据。

## 主题、缩放与键盘

- [ ] 浅色和深色页面自动采用对应主题。
- [ ] 在 100%、125%、150% 缩放下无裁切、溢出和遮挡。
- [ ] 键盘可完成打开、导航、搜索、编辑、变量填写和插入。
- [ ] 焦点环清晰；启用减少动态效果后无位移动画。

建议对提示词库、变量表单、编辑器、导入确认和图片分批分别保存浅色、深色截图。
