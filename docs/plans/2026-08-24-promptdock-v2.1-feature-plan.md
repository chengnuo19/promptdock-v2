# PromptDock V2.1 功能扩展实施计划

> 状态：仅保存计划，尚未实施  
> 日期：2026-08-24

## 概要

在现有 PromptDock V2 基础上增加三组能力：

- 快速模式：点击现有按钮即可搜索并插入提示词。
- 回答收藏：收藏当前对话中的问答快照，并按会话同步到 Notion。
- `//` 快捷指令：直接在 ChatGPT/Gemini 输入框内搜索和插入提示词。

保留现有提示词管理、图片分批、响应式抽屉和“只插入、不自动发送”原则。计划制定时的基线为 28/28 项测试通过，lint 和 build 通过。

## 实现变更

### 1. 快速查找模式

- 点击启动按钮默认打开快速模式，搜索框自动聚焦；“管理提示词”进入现有完整工作台，每次重新打开仍回到快速模式。
- 空搜索显示最多 5 条收藏和 5 条最近使用记录并去重；提供“浏览全部”入口。
- 新增统一的纯函数搜索排序，供快速模式和 `//` 菜单共用：
  1. 标题完全匹配；
  2. 标题前缀；
  3. 标题包含；
  4. 标签匹配；
  5. 正文匹配；
  6. 同分时依次按收藏、最近使用时间和标题排序。
- 支持方向键、Enter、Escape 和鼠标操作。
- 含变量的模板进入紧凑变量步骤；同名变量只显示一次，缺失时阻止插入并聚焦首个错误项。
- 输入框已有文字时保留“追加、替换、取消”选择；插入成功后关闭抽屉并聚焦网页输入框，失败时保留当前搜索和变量内容。

### 2. `//` 快捷指令

- 仅当 `//` 位于输入框开头或空白、换行之后时触发，避免网址、路径和代码误触。
- 菜单定位在光标附近并限制在可视区域；无法取得光标矩形时退回到输入框上方。
- 空查询显示收藏与最近使用，合计最多 8 条；继续输入后实时使用统一搜索排序。
- 选择模板后只替换光标前的 `//关键词` 命令片段，保留输入框前后文字，并将光标移动到插入内容末尾。
- 含变量时原地切换为迷你表单：
  - Tab 切换字段；
  - Ctrl+Enter 完成插入；
  - Escape 先返回结果菜单，再次按下关闭；
  - 变量值仅保留到本次操作结束。
- Escape 关闭菜单但保留已输入的命令文字；网页内容或光标位置失效时安全关闭。
- 中文输入法组合输入期间不拦截按键，也不提前触发搜索。
- 扩展 `SiteAdapter`，增加光标文本快照、范围替换和聚焦方法，同时兼容 textarea、input 与 contenteditable。

### 3. 回答收藏与会话定位

- 新建独立 `ConversationAdapter`，避免把易变化的消息 DOM 选择器混入现有输入框适配器。
- ChatGPT 和 Gemini 每条可见 AI 回答的原生操作栏旁注入星标按钮；重复扫描、响应重建和 SPA 导航不得产生重复按钮。
- 点击星标立即保存“对应用户问题 + AI 回答”的本地快照，不在同步时重新抓取。
- 使用站点、会话路由 ID、消息 ID 和内容摘要生成稳定定位信息；重新渲染后仍能恢复收藏状态。
- 工作台增加“回答收藏”页面，仅显示当前对话的收藏，支持：
  - 问题与回答摘要；
  - 本地、同步中、已同步、失败状态；
  - 跳转到原回答并短暂高亮；
  - 取消收藏；
  - 同步当前对话。
- 未同步收藏取消后直接删除；已同步收藏取消后保留隐藏记录和远端状态，重新收藏不会重复上传。任何取消操作都不删除 Notion 内容。
- 捕获结构统一为语义块和富文本片段，保留段落、标题、列表、引用、链接、代码及语言标识；公式保存为 LaTeX 文本，图片和附件只保留说明与可用原链接。

### 4. Notion 设置与同步

- 设置页增加：
  - 持久保存的内部集成令牌、掩码显示、连接测试和清除操作；
  - 多个“目录名称 + Notion 数据库链接”；
  - 数据库权限验证、重命名和删除保护。
- 每个目录绑定一个 Notion 数据库。插件自动解析链接、取得当前 data source ID 并识别标题字段；数据库只强制要求标题字段，平台、来源链接和同步信息写入页面正文。
- 用户首次同步某段对话时选择目录；首次成功创建页面后，该对话固定使用该目录。一个网页对话对应一个 Notion 数据库页面，后续只追加尚未同步的收藏。
- 页面创建和正文追加通过 Manifest V3 后台 service worker 完成：
  - Manifest 增加 `https://api.notion.com/*` host permission；
  - 固定使用 Notion API，不接受任意远程 URL；
  - 使用类型化消息处理连接测试、目录验证和会话同步；
  - 使用 `2026-03-11` API/data source 结构。
- 创建页面时仅写入数据库实际的标题属性，符合 Notion 的 [Create a page](https://developers.notion.com/reference/post-page) 约束；每条收藏按“问题—回答—时间—来源”追加到同一页面。
- 内容按最多 100 个子块分批追加，并限制请求大小，符合 [Append block children](https://developers.notion.com/reference/patch-block-children) 和 [Request limits](https://developers.notion.com/reference/request-limits)。
- 请求串行化并控制在平均每秒 3 次以内；遇到 429 按 `Retry-After` 重试，401/403 提示检查令牌、集成能力和数据库共享权限。集成至少需要 Read content 与 Insert content；参见 [Integration capabilities](https://developers.notion.com/reference/capabilities)。
- 每批成功后立即保存进度；普通失败保留当前未同步记录。无法判断远端是否已接收的网络中断标记为“需要检查”，不自动重复追加。
- 已映射页面出现 404 或无权限时不静默新建副本，而是提示用户检查 Notion；提供明确确认后的“在原目录重建页面”操作。
- 已被本地会话引用的目录不能直接删除；使用中的目录只能改显示名称，不能替换数据库目标。

## 数据与接口

### `SiteAdapter`

增加以下能力：

- `readSelection(composer)`：返回纯文本、选区起止位置和光标矩形。
- `replaceRange(text, range, composer)`：替换指定命令片段。
- `focusComposer(composer)`：重新聚焦网页输入框。

### `ConversationAdapter`

新增独立接口，用于：

- 获取稳定会话标识、标题和来源 URL；
- 枚举 AI 消息及其操作栏；
- 提取对应问答快照；
- 生成和解析消息定位器；
- 跳转并高亮原回答。

### 本地存储

- `promptdock_answer_bookmarks_v1`：收藏、隐藏记录、会话映射和分批同步状态。
- `promptdock_notion_config_v1`：目录名称与已验证数据库信息。
- `promptdock_notion_secret_v1`：Notion 令牌。
- `PromptDockStateV2` 和现有 `promptdock-backup` schemaVersion 2 保持不变，不迁移或重置已有提示词。
- Notion 令牌不进入 React 全局状态、日志、错误文本或任何 JSON 备份；收藏数据在本版本也不并入现有提示词备份。
- 扩展版本升级为 `2.1.0`，除 Notion host permission 和后台 service worker 外不新增权限。

## 测试与验收

### 自动测试

- 搜索权重、收藏/最近分组和稳定排序。
- `//` 边界识别、中文输入法、选区替换和变量校验。
- textarea、input、contenteditable 的光标读取与局部写入。
- 问答配对、语义内容解析、收藏切换、隐藏记录和会话隔离。
- Notion 块转换、长文本拆分、100 块分批和同步进度恢复。
- ChatGPT/Gemini 回答操作栏识别、星标单实例、消息重建和 SPA 会话切换。
- 跳转定位及原消息缺失降级。
- 快速抽屉与快捷菜单不遮挡网页发送键。
- Notion 令牌和数据库验证、首次建页、后续复用、未同步项过滤，以及 401、403、404、429、超时和部分批次失败。
- 删除目录保护及令牌不进入备份。
- `npm test`、`npm run lint`、`npm run build` 必须全部通过。

### 浏览器与实站验收

- 更新浏览器测试页面和浅色/深色截图，覆盖快速搜索、斜杠菜单、变量表单、回答收藏、目录选择和 Notion 设置。
- Chrome 与 Edge 分别加载新 `dist`，在 ChatGPT 和 Gemini 登录态验证长对话、重新生成回答、SPA 切换、窗口缩放、100%/125%/150% 缩放以及浅深主题。
- 使用真实 Notion 内部集成和测试数据库验证首次建页、同会话追加、失败重试和权限错误。
- 无法取得登录态或令牌的项目必须在验收报告中明确标为“未验证”，不得用自动测试替代实站结论。

## 默认边界

- 仍为个人加载已解压扩展，不发布商店，不加入账号、云同步、遥测或自动发送。
- 除用户手动执行的 Notion 测试和同步外，不产生其他远程请求。
- 不上传回答中的本地图片或临时媒体，不自动迁移或删除 Notion 页面。
- 不加入回答全局搜索库、提示词 AI 优化、多步骤流程和上下文卡片；这些留作后续版本。
