# PromptDock V2

PromptDock 是一个面向 ChatGPT 与 Gemini 网页端的本机提示词工作台。扩展在当前输入框旁显示一个小按钮，并以不改变网页布局的右侧抽屉管理、填写和插入提示词。

## 功能

- 适配 `chatgpt.com`、`chat.openai.com` 与 `gemini.google.com`。
- 提供 20 条中文内置模板，覆盖写作办公、学习科研、数学建模、编程开发和分析规划。
- 支持个人提示词、一级文件夹、多标签、收藏、搜索；排序按标题匹配度、收藏、使用次数、最近使用依次决定。
- 支持 `{{变量名}}`，以及带默认值的 `{{变量名:默认值}}`（半角或全角冒号均可）。变量未填写且没有默认值时不会插入；上次填写的值会在下次插入同一条提示词时预填。
- 任意提示词可一键创建个人副本；内置模板的副本不会覆盖原模板。
- 提示词库支持多选后批量移动文件夹、批量添加标签、批量删除。
- 在输入框行首或空格后输入 `//` 可唤出内联菜单，直接搜索并插入提示词。
- 回答操作栏的星标可收藏当前问答快照。收藏面板可在「当前对话」与「全部对话」间切换，支持按对话标题、问题或回答搜索；当前对话内的收藏可点击跳转（定位不到会明确提示），其他对话的收藏则打开原对话。
- 回答收藏可导出为 Markdown（按对话分组），也可按对话同步到 Notion 数据库（需自行提供内部集成令牌）。
- 多个标签页同时打开时，任一处的改动会实时同步到其他标签页，不会互相覆盖。
- 鼠标进入页面最右侧 32 px 时显示条纹把手；悬停约 0.2 秒展开当前对话的提问列表，ChatGPT 与 Gemini 均可用（Gemini 无同源会话接口，直接读取页面已渲染的提问）。
- 提问列表可点击跳转：滚动到对话中对应的那条提问并短暂高亮，支持键盘 Tab 与回车。长对话中尚未加载到页面的旧提问会置灰并说明需要向上滚动加载。列表标出当前视口所在的提问，每条默认两行截断、悬停或聚焦时展开全文。
- 长列表优先消费面板内的滚轮/触控板滚动，到顶或到底后才交还页面；结果仅在本次页面内存中缓存，对话新增提问后会自动重新读取；超过 80 条时保留最新的 80 条。
- 输入框已有内容时明确选择追加或替换；PromptDock 永远不会自动发送。
- 内置模板可编辑、隐藏、单条恢复或全部恢复。
- JSON 完整备份、校验后合并或替换。
- 图片按 1–10 张分批附加；每批附加后由用户在网页中手动发送。
- 抽屉顶部与网页顶部对齐；大窗口默认宽 360 px、高度最多为视口的 80%，宽度可在 360–640 px 间调整。
- 非最大化窗口自动压缩为 320 px，并根据输入框位置缩短高度，使抽屉底部停在输入区上方；极窄窗口左右保留 8 px，内容在抽屉内部滚动。

## 安装

本项目只交付“加载已解压扩展”，不生成 CRX。

### Chrome

1. 打开 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目的 `dist` 文件夹。
5. 打开或刷新 ChatGPT/Gemini 页面。

### Edge

1. 打开 `edge://extensions/`。
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择 `dist` 文件夹。
5. 打开或刷新 ChatGPT/Gemini 页面。

网页改版后若按钮没有出现，请先刷新页面并在扩展管理页确认 PromptDock 已启用。

扩展申请 `storage` 权限，以及 `https://api.notion.com/*` 的主机权限。提示词、文件夹、收藏、使用记录和回答快照都只保存在当前浏览器的 `chrome.storage.local`；只有在你手动点击「同步当前对话」时才会向 Notion 发出请求，Notion 令牌单独存放且不会写入 JSON 备份。不使用 Notion 同步时，扩展不发起任何网络请求。

## 站点适配

每个站点的定义集中在 `src/sites/<站点>.ts`，包含输入框查找、锚点与图片上传入口、对话消息选择器、会话接口路径。输入框读写、回答收藏与提问列表三层都从这里取值，新增站点是「加一个 `src/sites` 文件 + 在 `manifest.json` 的 `matches` 里加一行」。`src/sites/index.test.ts` 会校验每个站点定义都填齐了必需字段。

```powershell
npm run lint
npm run build
```

```powershell
npx vite --host 127.0.0.1
```

备份规则见 [JSON 备份说明](docs/JSON_BACKUP.md)，人工实站步骤见 [验收清单](docs/MANUAL_ACCEPTANCE_CHECKLIST.md)。

## 边界

不包含账号体系、自动云同步、遥测、全局快捷键、多级文件夹、提示词拖拽排序、图片拖放、自动发送、Firefox 或商店发布流程。唯一的远程调用是用户手动触发的 Notion 同步。
